# Project 3: Spots

This is the third project of the Software Engineering program at TripleTen. It is a simulated social media page with a user's profile and posts. It was created using HTML, CSS and Javascript, based on the design brief on Figma.

**Project Features**

- All elements are responsive and content is adjusted to fit various screensizes using media queries.
- Excess text is truncated, ending with ellipses.
- Grids are used to responsively position cards containing mixed media.
- HTTP requests are used to communicate with the server API to receive, modify, and delete all information about the user, their posts, and whether the posts are 'liked' or not. All changes are persistent.
- UI reflects pending changes during asynchronous operations

**Technologies**

- Developed with Node.js
- Bundled with Webpack
- Transpiled with Babel
- Version control managed by Git
